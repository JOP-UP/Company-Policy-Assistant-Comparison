Benchmark conclusion

The rules-based approach was the fastest in the benchmark because its calculations were performed locally and programmatically, but it failed the semantic question about working from Spain because the scoring rules selected the wrong policy. More rules and synonyms could improve this baseline, although that would also increase maintenance. Both LLM-based approaches answered the tested questions correctly. The vector method was slightly faster in the recorded LLM response times and used about 90% fewer LLM tokens, primarily because only the retrieved policies were included in the prompt instead of the complete policy database.

The preferred approach is therefore LLM + Vector because it achieved the same observed answer quality as LLM-only while being substantially more token-efficient and more scalable as the policy database grows. RAG also supplies a smaller, semantically relevant evidence set to the LLM. The current benchmark did not show a higher hallucination rate for the LLM-only method, so reliability beyond the tested questions should be treated as a hypothesis rather than a demonstrated result.
